# Raphbee Portfolio

Personal portfolio website for Raphbee — focused on e-commerce, web development, business automation, and practical AI integrations.

## Project status

Initial repository setup. The website design system and Next.js application scaffold will be added in the next setup step.

## Reference direction

The visual direction takes inspiration from the structure and presentation of Emmanuel Adeyemi's portfolio, while using original Raphbee branding, copy, photography, and project materials.

## Planned stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons
- Vercel deployment

## Getting started

The application scaffold and local development instructions will be added once the Next.js project has been initialized.
